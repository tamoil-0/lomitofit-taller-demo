# Auditoría UX/UI focalizada
1. Observa header, hero, producto, filtros, carrito y versión móvil.
2. Revisa jerarquía tipográfica, contraste, espaciado, estados de interacción, etiquetas y legibilidad.
3. Reporta máximo 5 hallazgos priorizados (alto/medio/bajo), con archivo y ejemplo.
4. Propón cambios mínimos, no agregues librerías salvo autorización.
5. Si se autoriza implementar, cambia un bloque a la vez, valida y reporta.
