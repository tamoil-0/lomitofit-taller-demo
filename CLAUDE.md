# Contexto persistente: LOMITO FIT

Proyecto educativo de ecommerce en React + Vite para un taller. No es una tienda en producción.

## Reglas
- Antes de cambiar código, explica el archivo y el objetivo en máximo 3 líneas.
- Trabaja en una tarea pequeña a la vez; evita refactorizar archivos no solicitados.
- No agregues dependencias sin justificarlo. No implementes pagos, envíos de correos ni APIs externas reales.
- Mantén separación entre catálogo, interfaz y estilos; componentes accesibles y responsive.
- Después de una modificación, ejecuta pruebas y build si hay entorno; informa fallos sin inventar éxito.
- No leas secretos de .env ni hagas push directo a main sin revisión.
- Usa datos, fotos y precios ficticios del brief. No afirmes que la guía de tallas es universal.
- Al terminar, responde con: cambios realizados, prueba ejecutada, resultado y próximo paso.
